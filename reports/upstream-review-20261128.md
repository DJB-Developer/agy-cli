## 1. P1：静默重试快速返回，但与额度冷却分开

0.1.157 在 prompt 运行期间增量读取本轮新增的完整日志行，发现特定 bare 429 重试就结束本轮；503 no-capacity 则仅在首输出前结束。支持半行下次补读，忽略 prompt 前旧日志。目的是避免 CLI 静默重试造成长时间无响应。[实现与测试](https://github.com/magpie-community/plugins/commit/25b0979cdf9367c27a60be0aab3b2fe48e2f4458)

本地目前只在部分结束/错误路径调用 `lastAgentError()`，未见运行中的同类 watcher。值得借鉴提前暴露真实失败的机制，但**bare 429 不证明额度耗尽，不能写入 QUOTA_EXHAUSTED 冷却**；当前待提交实现的严格识别应保留。已产生文本/工具时必须保留 noRetry，不能自动重放。上游也承认没有真实 1.5.13+ 429 样本验证其日志格式，且立即返回会放弃 CLI 可能成功的短暂重试。

移植前离线验收：旧日志、分段写入、日志截断/轮转、取消、输出后的失败、工具副作用，以及普通 429 不产生额度窗口。只处理日志错误，不需要同步提示词改写策略。

## 2. P1：跨账号模型别名保护

上游较早的 [`f52a515`](https://github.com/magpie-community/plugins/commit/f52a5151def2ff3085a301c3e82634e5fc301ed0) 针对“账号 A 无目标模型却通过 family alias 返回另一个模型，账号 B 实际有目标模型”加保护：只读同一 agy 路径下其他仍存在账号的有效目录缓存；若其他账号明确提供目标模型，拒绝本账号静默替代。它没有在插件内部实现账号轮转。

本地 `resolveCatalogAlias()` 仍有 sonnet/opus 等家族替代，未见 `anotherAccountLists` 同类检查。多账号路由时，此项比增加更多备用重试更值得优先补：**保持用户请求模型的语义，不以另一个模型的成功回答掩盖账号不支持。**

应先复现双账号目录 fixture，再适配本仓目录隔离和宿主错误契约；不要为检查其他账号启动 CLI、查余额或读取凭据。上游使用 400 不代表当前运行的 Magpie 必然据此换号，需端到端确认其路由策略。缓存过期、账号删除、日期/effort 后缀与用户明确别名均要覆盖。

## 3. P2：宿主更新交接时补读会话索引

上游 [`4836dc1`](https://github.com/magpie-community/plugins/commit/4836dc1) 在 `takeParked()` 重读持久索引、只合入目标 key 的更新记录，并尊重已消费标记，修复旧宿主晚于新宿主启动才写入 checkpoint 的交接窗口；同时将保留上限 32 改为 256。

本地有跨进程保存合并与锁，但 `takeParked()` 只调用一次性 `loadParked()`，因此值得补双进程时序测试。优先借鉴“读到晚写入记录”，**不必顺手扩大上限**；继续验证账号绑定、工作目录、历史和工具调用身份，避免为复用会话而放宽隔离。

## 与当前额度改动的关系

当前工作区已实现：明确耗尽错误 → 固定 resetAt → 当前账号/模型本地冷却 → 向宿主返回可用路由信号；无 reset 仅显示未知，不永久锁定。模型家族范围不推断成整个 Individual/Third-party 额度池。详见[实现及离线测试记录](/Users/gold/code/agy-cli/reports/quota-cooldown-20261128.md)。

**建议顺序：**先验收现有额度信号在实际宿主上的账号/备用路由；随后补跨账号模型保护与静默失败快速返回；再处理宿主交接会话补读。备用通道仍由宿主配置/选择，插件不另建自动换号循环。实际宿主的版本、候选组和 noRetry 行为本轮尚未端到端验证。

T3 Code 已另行核对到 `f5bf14070f8145a63e322aab7bb2fbdca1780ee8`，详见[最新复核](/Users/gold/code/agy-cli/reports/t3-agy-review-20261128.md)。新增重点是超时前依据本轮完成证据避免误报失败。T3 按失败线程的 reset 安排继续，不是本仓的账号/模型冷却表，也不是自动账号轮转。当前冷却实现还需核查登录变化但 usage 先读取、effort 全档归组、相对 reset 首次时间锚和宿主 noRetry 契约；这些是静态审查风险，不是已复现缺陷。当前用于归组的是 selected model，尚无 executed-model 证据，不能称已验证的实际执行模型。
